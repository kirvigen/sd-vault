СЕЙФ НА КАРТЕ
=============

Зашифрованная папка, которая открывается на любом компьютере без установки
программ и без прав администратора. Файлы зашифрованы стандартным форматом
age (https://age-encryption.org) и на карте всегда лежат только в
зашифрованном виде.


ЧТО ЛЕЖИТ НА КАРТЕ
------------------

  vault-windows.exe     программа для Windows
  vault-macos           программа для macOS (Intel и Apple Silicon)
  vault-linux-amd64     программа для Linux на обычных ПК
  vault-linux-arm64     программа для Linux на ARM (Raspberry Pi и т. п.)
  README.txt            этот файл
  vault/                сам сейф (появится после первого запуска)
    key.age             ключ сейфа, зашифрованный вашим паролем
    index.age           зашифрованный список: имена файлов и папок
    index.age.bak       предыдущая версия списка, на случай сбоя
    blobs/              зашифрованные файлы, по одному на каждый ваш файл

Все программы работают с одной и той же папкой vault/.


КАК ОТКРЫТЬ
-----------

1. Вставьте карту и запустите программу для своей системы:
     Windows — двойной щелчок по vault-windows.exe;
     macOS   — двойной щелчок по vault-macos (откроется Терминал);
     Linux   — в терминале: /media/<вы>/<карта>/vault-linux-amd64
2. В окне программы введите пароль. При первом запуске пароль задаётся
   дважды и создаётся пустой сейф. Пароль не меньше 8 символов.
   ВОССТАНОВИТЬ ПАРОЛЬ НЕЛЬЗЯ: без него файлы не прочитает никто.
3. Откроется браузер с вашими файлами. Если не открылся — скопируйте адрес
   из окна программы. Адрес работает только на этом компьютере
   (127.0.0.1) и только пока программа запущена.

В браузере можно: смотреть картинки, PDF, текст, видео и музыку; скачивать;
загружать файлы и целые папки (кнопками или перетаскиванием); создавать
папки, переименовывать и удалять.


ОБНОВЛЕНИЯ
----------

При запуске программа на пару секунд заглядывает на GitHub
(github.com/kirvigen/sd-vault) и, если вышла новая версия, спрашивает,
обновиться ли. Ответ «д» — скачает и заменит программы, которые лежат на
карте, и перезапустится; Enter — продолжит на текущей версии. Сейф при этом
не трогается, пароль не отправляется. Без интернета вопрос просто не
появится.

Каждое обновление подписано ключом автора, и программа проверяет подпись
до замены: подменённый или повреждённый файл не установится.

Не заглядывать в интернет вовсе: запускать с ключом -no-update (в
Терминале или в ярлыке Windows).


КАК ЗАКРЫТЬ
-----------

Кнопка «Закрыть сейф» в браузере или Ctrl+C в окне программы. Программа
допишет начатое, остановится и забудет ключ. После надписи «Сейф закрыт»
карту можно вынимать.

Каждое изменение записывается на карту сразу и атомарно (временный файл →
сброс на диск → переименование), поэтому даже выдернутая на ходу карта не
испортит сейф: пропадёт максимум файл, который загружался в этот момент.


ВАЖНО ЗНАТЬ
-----------

* Просмотр в браузере расшифровывает файл в памяти и на диск компьютера его
  не пишет. А вот «Скачать» сохраняет РАСШИФРОВАННУЮ КОПИЮ на компьютер
  (обычно в «Загрузки»). Если открыли файл во внешней программе через
  «Скачать», после работы удалите эту копию и очистите корзину.
* Браузеру запрещено кэшировать файлы сейфа, но операционная система может
  выгрузить память в файл подкачки. На чужом или общественном компьютере
  открывайте только то, что действительно нужно.
* Пока сейф открыт, его видит любая программа на этом компьютере, которая
  знает адрес из окна программы. Не открывайте сейф на компьютере, которому
  не доверяете: вирус может перехватить и пароль, и файлы.
* Резервная копия: просто скопируйте папку vault/ целиком куда угодно — она
  зашифрована. Восстановить = положить её обратно рядом с программой.


macOS: «НЕ УДАЁТСЯ ПРОВЕРИТЬ РАЗРАБОТЧИКА»
-----------------------------------------

Программа не подписана сертификатом Apple, поэтому Gatekeeper может её
заблокировать. Снимите карантин один раз (в Терминале, имя карты своё):

  xattr -d com.apple.quarantine /Volumes/КАРТА/vault-macos

Другой путь: Системные настройки → Конфиденциальность и безопасность →
внизу «Всё равно открыть» после первой неудачной попытки запуска.


Windows: «СИСТЕМА WINDOWS ЗАЩИТИЛА ВАШ КОМПЬЮТЕР»
------------------------------------------------

Это SmartScreen: программа не подписана. Нажмите «Подробнее» →
«Выполнить в любом случае». Если файл скачан из интернета, можно один раз
снять пометку: правый щелчок по vault-windows.exe → Свойства →
галочка «Разблокировать» → OK.


Linux: «Permission denied»
--------------------------

Если карта смонтирована без права запуска, скопируйте программу (в ней
нет ваших данных) и укажите путь к сейфу:

  cp /media/<вы>/<карта>/vault-linux-amd64 /tmp/vault
  chmod +x /tmp/vault
  /tmp/vault -dir /media/<вы>/<карта>/vault


КАК ДОСТАТЬ ФАЙЛЫ БЕЗ ЭТОЙ ПРОГРАММЫ
------------------------------------

Всё в папке vault/ — обычные файлы age. Их расшифрует официальная утилита
age (https://age-encryption.org; macOS: brew install age; Debian/Ubuntu:
apt install age; Windows: winget install FiloSottile.age или архив с
https://github.com/FiloSottile/age/releases).

Пароль защищает только ключ key.age, а файлы зашифрованы этим ключом.
Утилита age сама спросит пароль, когда ей передают key.age через -i.

1. Список файлов (спросит пароль):

     age -d -i vault/key.age vault/index.age > index.json

   В index.json у каждого элемента есть "name" (имя), "parent" (id папки,
   пустой — корень), "dir": true у папок и "blob" — путь к зашифрованному
   содержимому, например "blobs/3f/3fa1c0….age".

2. Нужный файл (спросит пароль):

     age -d -i vault/key.age -o "имя-файла.jpg" vault/blobs/3f/3fa1c0….age

Чтобы не вводить пароль на каждый файл, можно один раз расшифровать ключ:

     age -d vault/key.age > key.txt
     age -d -i key.txt -o "имя-файла.jpg" vault/blobs/3f/3fa1c0….age

key.txt и index.json — ОТКРЫТЫЙ ТЕКСТ: key.txt открывает весь сейф без
пароля. Удалите их сразу после работы.

Если index.age повреждён, то же самое работает с index.age.bak.
